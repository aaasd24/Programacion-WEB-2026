# 🚀 Proyecto de Programación Web 2026

Repositorio oficial para el desarrollo, documentación y seguimiento del proyecto correspondiente al semestre 2026-II.

### 📋 Descripción

Este repositorio contiene el código fuente, documentación, avances y recursos relacionados con el proyecto desarrollado durante el curso de Programación Web 2026.

El objetivo es mantener centralizado el trabajo del equipo y proporcionar una referencia clara sobre el desarrollo y evaluación del proyecto.

### 🎯 Objetivos del proyecto
1. Desarrollar una aplicación web funcional.
2. Aplicar buenas prácticas de desarrollo de software.
3. Documentar el proceso de desarrollo.
4. Mantener un control organizado de los avances.
5. Identificar y solucionar problemas técnicos.
6. Preparar las entregas correspondientes al semestre.
7. Cumplir con todas las rubricas presentadas por todos los profesores en este semestre

Durante el desarrollo del proyecto se trabajará en los siguientes aspectos:

- 📈 Avances del proyecto.
- 💻 Programas y ejercicios sencillos.
- 📝 Anotaciones técnicas.

- 📚 Especificaciones del código base.
- 📖 Documentación del proyecto.
